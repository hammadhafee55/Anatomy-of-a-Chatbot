Glossary

The vocabulary you need to follow any LLM conversation.

Token
A chunk of text, often a word or word piece, that the model reads and writes. It is the unit of length and cost.
Embedding
A vector of numbers that represents a token’s meaning, so similar ideas sit close together.
Parameter
A learned number (weight) inside the network. Modern models have billions to trillions.
Logit
The raw score the model gives each possible next token before softmax makes it a probability.
Temperature
A setting that sharpens or flattens the probabilities. Low is predictable, high is varied.
Top-p
Sampling from the smallest set of tokens whose probabilities add up to p.
KV cache
Stored keys and values of earlier tokens, reused so each new token is cheap to compute.
Fine-tuning
Further training on curated examples so the model follows instructions and a chosen style.
RLHF
Reinforcement learning from human feedback: people rank answers, and the model learns to prefer the better ones.
RAG
Retrieval-augmented generation: fetch relevant documents and add them to the prompt before answering.
Inference
Running a trained model to produce answers, as opposed to training it.
Hallucination
A fluent but false or unsupported statement produced by a model.
